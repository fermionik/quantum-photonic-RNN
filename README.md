A single optomechanical node is driven by a pair of single photons in consecutive time frames. The data are encoded in the temporal mode of each photon as a superposition of the first two Hermite--Gaussian (HG) functions. A control pulse, itself a superposition of two HG functions, spans both frames. At the end of the pair of frames the phonon number is measured, and $S$ repetitions estimate $P_b(n)$, $n=0,1,2$. These probabilities feed a leaky-$\tanh$ update of the control-pulse weights, which is the recurrent element, and a linear readout that predicts the next pair of photon modes. The readout is trained by ridge regression. The feedback weights are trained by simultaneous-perturbation stochastic approximation (SPSA), which needs only noisy loss evaluations from the hardware. The system is trained on 50 double frames and then run closed loop for 5 steps. With $R=6$ parallel nodes and $S=1000$ shots it forecasts the mode angle with a mean RMS error of $4.9^\circ$ (mode fidelity $0.990$). This is shot-noise limited: with exact probabilities the error is $1.2^\circ$.# quantum-photonic-RNN
